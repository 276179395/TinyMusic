# 原生 iOS 验收清单

> 目标：S3 网盘播放 + 离线缓存 + iCloud + Liquid Glass。当前状态以本文件为准。

## 已实现（本机已验证）

- SwiftUI 原生工程（iOS 18.0+ / Swift 6 / XcodeGen），无 CocoaPods、无 Lynx。
- S3-only Rust FFI：ios/crates/ffi 直接调用 core（../desktop/crates/core），不链接 app/server/provider。
- S3 连接配置、歌单/曲目浏览、AVPlayer 流式播放。
- 离线缓存：单曲/歌单入队、URLSession background、索引、歌词/封面 sidecar、缓存页、删除/清空、上限、仅 Wi-Fi。
- 缓存优先播放；缓存目录排除 iCloud 备份。
- iCloud：Keychain 凭据（可同步）、KVS 同步 S3 非敏感配置 + EQ；缓存不同步。
- Liquid Glass：iOS 26+ glassEffect；iOS 18–25 材质退路。已在 iPhone 16 Pro / iOS 18.5 构建并启动验证。
- 歌词页、播放队列页、10 段 EQ（MTAudioProcessingTap + 12 套预设）、Liquid Glass 迷你播放条。
- 播放页可拖动 seek + 时间标签；进度条固定宽度，点/拖都能定位。
- 单元测试：PlaybackQueue、LyricsStore、EQ、CloudSettings；UI 冒烟测试 4 个。
- iOS 的构建 / 单测 / archive 全部在本地跑（下面的命令），GitHub Actions 不再构建 iOS：发布走本地打包上传 App Store。
- 缓存页曲目可直接点播；停掉 S3 桩后验证过本地缓存播放。
- 本地 S3 桩 + seed 脚本，已验证缓存下载与播放。

## 待完成 / 待验

- iCloud 双设备真实同步需真机 + 付费开发者账号验证；模拟器只能验证本地 KVS。
- 真实 S3 矩阵（AWS/R2/MinIO）只做了本地桩；需要真实桶凭据跑一轮。
- 后台/锁屏/来电/拔耳机/AirPlay 真机验收。
- App Store 归档已能产出无签名 .xcarchive；上传前需要 Xcode 登录账号、App ID 开启 iCloud KVS、profile 含 ubiquity-kvstore entitlement、只读演示桶。
- 本机已尝试签名构建：报 No Accounts + iOS Team Provisioning Profile 不含 iCloud capability，属于账号/后台配置问题。
- 旧 Lynx 归档（ios/legacy-lynx）确认稳定后删除。

## 已知环境注意

- Xcode 的 Swift 宏插件需要 sandbox-exec；在 DSH 的 workspace-write 下会报 sandbox_apply: Operation not permitted。
  project.yml 已给 Swift 加 -disable-sandbox，命令行构建可用；xcodebuild test 的测试 runner 仍可能受 PTY 限制。
- 没有 iCloud 登录时 KVS 不报错但不跨设备；Keychain 同步同样要求 iCloud 钥匙串开启。
