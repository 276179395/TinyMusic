TinyMusic隐私政策内容声明

支持

TinyMusic iOS · 1.0

第一次使用

  1. 准备一个 S3 兼容存储桶，例如 AWS S3、Cloudflare R2 或 MinIO。
  2. 在 App 里填 endpoint、region、bucket、prefix、Access Key 和 Secret Key。
  3. 桶内按 前缀/歌单/歌手 - 歌名.m4a 放文件；同名 .lrc 和 .jpg/.png/.webp 会作为歌词和封面。
  4. 保存后回到资料库，选择歌单播放。

离线缓存

在歌单或歌曲上点“缓存”，App 会用后台 URLSession 把音频、歌词、封面存进沙盒。缓存只用于 App 内播放，不能导出，也不会进入 iCloud 备份。

iCloud

S3 密钥写入 Keychain；开启 iCloud 钥匙串后可在自己的设备间同步。非敏感设置走 iCloud KVS。缓存不同步。

常见问题

为什么歌单是空的？ 检查 prefix 是否和桶内目录一致，以及 Access Key 是否有 ListBucket/GetObject 权限。

为什么只能看不能收藏？ 只读密钥无法写 favorites.json，收藏会退回本机。

为什么播放失败？ 确认 endpoint 使用 HTTPS、bucket 允许 CORS/公开读取，或使用预签名 URL 所需权限。
