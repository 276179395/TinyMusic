# 桌面回归清单

桌面改动前后都要执行这份清单。

## 自动检查

    cd desktop
    pnpm -F @tinymusic/shared test                  # 公共 TS 逻辑（34 个）
    node packages/theme/scripts/gen.mjs --check     # 令牌产物与 src/app.css 一致
    cargo test --workspace                          # 含桌面壳、crates/app、crates/core
    pnpm build
    cargo build -p tinymusic

## 手动检查（启动桌面后）

    pnpm tauri dev     # 或 ./target/debug/tinymusic

日志里应出现 `[tinymusic] 流代理: http://127.0.0.1:<port>`。

- [ ] 首次启动可从网盘页进入设置，选择 WebDAV，填写服务地址、音乐根目录和认证信息后测试连接
- [ ] 网盘 → 打开包含中文路径的歌单 → 双击播放，进度条走动，还能拖动进度
- [ ] 播放页：封面、标题、进度、上一首/下一首、随机/循环
- [ ] 重新打开应用后恢复上次的曲目和进度
- [ ] 歌词逐行高亮，点句跳播
- [ ] 均衡器改一段增益后声音有变化，重启后设置还在
- [ ] 已有本地下载出现在下载页，能本地播放
- [ ] 将 MP3 副本改名为 `.flac`，FLAC 副本改名为 `.mp3`，分别从本地、下载、播放缓存、WebDAV 与 S3 播放。确认播放和拖动进度正常，播放页标签与文件实际格式一致。另用 AAC、M4A、OGG 和 WAV 验证当前 WebView 支持的格式仍能播放。
- [ ] 左下角显示「设置」，分隔线下依次显示「网盘」和「本地」。添加本机歌曲后点「本地」同一行右侧的加号新建收藏夹，把部分曲目加入收藏夹，检查「本地」仍显示全部歌曲，收藏夹仅显示已加入的歌曲。切换标签播放，重启后列表和收藏夹仍在
- [ ] Windows 安装后在程序旁检查 `input`，macOS 在安装后首次启动时检查。程序旁不可写时，确认程序使用配置目录中的 `input`；开发版使用 `dev/input`。打开「添加音乐文件」和「添加文件夹」，确认都从 `input` 开始，可取消或选择其他位置。导入包含 MP3、FLAC、同名歌词、封面和其他文件的目录，确认子目录里的音频也被导入、原文件保留；重复导入同一目录不重复入库，选空目录时显示提示
- [ ] 在 `Music/Local` 检查每首导入歌曲和本机下载各有独立目录，文件字节和同名附属文件完好。收藏夹的 `track.json` 使用相对于音乐库根目录的路径。后台取回留在独立缓存中，手动下载后才显示在「本地」
- [ ] 点击歌曲旁的空心星加入收藏夹。双击收藏夹名称后按 Enter 保存，验证歌曲引用保留；点击收藏夹右侧红色垃圾桶后，收藏夹从侧栏消失，「本地」仍可播放原曲目
- [ ] 打开另一个音乐库，确认只浏览新目录；用「复制音乐库」复制到空目录后确认歌曲、收藏夹和相对引用仍可用，旧文件仍在
- [ ] 网盘下载（WebDAV 和 S3 分别跑一遍）：单曲下载和「下载全部」保存到音乐库的 `Local/歌曲名/` 下，原文件格式和字节保持一致；已有同名歌词和封面一并保存
- [ ] 下载完成后禁用网盘或断开网络，在下载记录中双击验证本地播放、拖动进度、歌词和封面
- [ ] 下载不存在的对象应记录失败；恢复对象后可从失败列表重试。重复下载同名曲目时，各份文件彼此独立
- [ ] 在线播放一首未下载的曲目，拖过三分之一或暂停等待时不创建缓存，实际播放覆盖三分之一后静默取回。切歌后任务可完成，下载记录保持原样
- [ ] 重播时优先命中手动下载，其次命中已完成的播放缓存。手动下载可复用缓存中的原文件与附属文件
- [ ] 设置中选择独立缓存目录并清空，清空只影响该目录里的播放缓存。手动下载和同目录其他文件仍在
- [ ] 清空时已有或排队的缓存任务应取消，清空完成后旧任务不会重新写入
- [ ] 网盘（WebDAV 和 S3 分别跑一遍）：歌单列表、试连、新建空歌单、排序、重命名、删除、校验
- [ ] 喜欢（WebDAV 和 S3 分别跑一遍）：红心 = 在「喜欢」目录里多一份副本；去网盘页把「喜欢」里的某首删掉，
      再进喜欢页刷新，那首不再出现（收藏只认这个目录，不看 favorites.json）
- [ ] 关闭到托盘或最小化后，双击托盘图标可恢复并聚焦主窗口；右键菜单仍可显示主界面、控制播放和退出。关闭窗口行为与设置一致
- [ ] 设置 → 外观 → 玻璃材质：关掉后卡片/浮层变成实色 + 1px 边框，结构（间距/圆角/尺寸）不变；
      再打开恢复毛玻璃。老系统（macOS 12 及更早）应默认是关的，并写明原因
- [ ] 主题标签可切换跟随系统、深色、浅色、自定义。主题包和背景下拉框与语言下拉框样式一致，主题包导入只接受 ZIP。
- [ ] 只有自定义显示主题包和导入入口。内置主题使用默认背景，切回自定义时恢复此前设置。
- [ ] 在自定义中切换浅色和深色主题包，确认底板提示、页面背景及控件材质同步变化。
- [ ] 开发版导入的主题写入配置目录的 `dev/theme`。安装版优先使用软件旁边的 `theme`，不可写时回退到配置目录。导入后保留原 ZIP，重启后主题仍可使用。
- [ ] 自定义背景的默认、纯色和本地图片可切换，重启后恢复选择。分别从浅色和深色进入自定义，确认同一纯色背景的效果一致。
- [ ] 导入「星夜」和「樱花」，确认只有樱花有落花动画。开启系统减少动态效果后，樱花仍显示静态底图。
- [ ] 导入「暮色」主题包，验证颜色和包内背景图片生效、重启保持选择，切回「应用外观」恢复此前的背景
