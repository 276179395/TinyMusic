# 桌面端文案与中英切换

界面支持简体中文和英文：默认跟随系统语言，也可以在 **设置 → 外观 → 语言** 里
手动选「跟随系统 / 简体中文 / English」，立即生效。语言偏好保存在
localStorage 的 `tinymusic.language`，和主题一样属于本机显示偏好。

## 写法

字典的键就是**中文原文**，中文模式原样返回，所以中文界面与改造前逐字一致；
英文模式查表，缺失时回落到中文原文（dev 下会在控制台 warn）。

```ts
import { t, tc, fmtPlayCount } from '../lib/i18n.svelte';

t('设置')                                  // 中文 → 设置；英文 → Settings
t('已检查 {n} 首', { n: 12 })              // 占位符替换
tc('tab', '歌曲')                          // 同一句中文在不同语境译法不同
fmtPlayCount(12000)                        // 中文 1.2万；英文 12K
```

- 所有用户可见文案（按钮、标题、tooltip、aria-label、toast、空状态、统计、
  对话框、菜单、骨架屏）都要走 `t()`。
- 动态字符串不要拼接：把整句当键，变量写成 `{name}` 占位符。
- 模板里 `{t('...')}` 会跟随语言切换。**模块级常量数组不会**：用
  `$derived`、函数，或在模板里 `t(item.label)`。
- Svelte 的 each 块变量不要叫 `t`，会遮住 import。
- 同一句中文需要不同英文时用 `tc(语境, 原文)`，词典键写成 `语境|原文`。
- 代码注释、console 日志、provider 返回的歌曲/歌手/专辑名、后端错误原文不翻译。

## 字典

| 文件 | 范围 |
| --- | --- |
| `src/lib/i18n/messages/common.ts` | 各页面共用的小词 |
| `src/lib/i18n/messages/shell.ts` | 侧边栏、设置、窗口按钮、toast、错误条 |
| `src/lib/i18n/messages/player.ts` | 播放器、队列、均衡器、歌词、曲目菜单 |
| `src/lib/i18n/messages/browse.ts` | 搜索、推荐、网盘、下载、导入、S3 完整性 |
| `src/lib/i18n/messages/details.ts` | 详情页、账号、列表行、骨架屏 |

`packages/shared` 里的 `qualityLabel()` / `fmtCount()` 保持纯函数、不依赖语言；
展示时用 `t(qualityLabel(q))` / `fmtPlayCount(n)` 包一层。

## 新增一条文案

1. 把界面上的中文原文写进 `t('...')`（占位符用 `{name}`）。
2. 在对应字典里加 `'中文原文': 'English'`，占位符保持同名。
3. 跑 `node tools/check-i18n.mjs`，确认 0 missing。
4. `pnpm build`。

## 系统语言与托盘

- 启动时读 `navigator.languages`：以 `zh` 开头用中文，其余用英文。
- 桌面壳的托盘菜单由 Rust 构建，前端在初始化和切换语言时调用
  `set_ui_language` 命令重画，所以托盘也跟着界面语言走。
