# 桌面回归清单

桌面是最初的产品基线，任何改动前后都要能跑完这一页。mobile 侧改公共库
（`crates/app` / `packages/shared` / `packages/theme`）时尤其要跑。

## 自动检查

    pnpm -F @tinymusic/shared test                  # 公共 TS 逻辑（34 个）
    node packages/theme/scripts/gen.mjs --check     # 令牌产物与 desktop/src/app.css 一致
    cargo test --workspace                          # 含 desktop 壳、crates/app、crates/core
    pnpm -F @tinymusic/desktop build
    cargo build -p tinymusic

## 手动检查（启动桌面后）

    pnpm tauri:dev      # 或 ./target/debug/tinymusic

日志里应出现 `[tinymusic] 流代理: http://127.0.0.1:<port>`。

- [ ] 首屏推荐能出内容（或按当前网络给出错误提示，不白屏）
- [ ] 搜索 → 结果列表 → 双击播放，进度条走动
- [ ] 播放页：封面、标题、进度、上一首/下一首、随机/循环
- [ ] 音质切换后仍是同一首、进度保留
- [ ] 歌词逐行高亮，点句跳播
- [ ] 均衡器改一段增益后声音有变化，重启后设置还在
- [ ] 下载一首：进度推进，完成后出现在下载页，能本地播放
- [ ] 网盘（配了 S3 的话）：歌单列表、试连、校验
- [ ] 托盘图标可点，关闭窗口行为与设置一致

发现退化先看 `mobile/docs/spike.md`，里面记了平台差异与已知坑。
