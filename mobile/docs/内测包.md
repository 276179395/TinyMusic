# TinyMusic mobile 内测包说明

> 面向：想在自己 iPhone 上装一份试试的同学。iOS 版正在开发中，功能与桌面端逐步对齐。

## 现在能做什么

- 搜索单曲 / 搜歌单、每日推荐（网易云目录）
- 播放（走本机 Rust 后端的流代理，支持后台播放、锁屏/线控、来电与拔耳机暂停）
- 全屏播放页：封面、进度、上一首/下一首、随机/循环、音质切换、歌词逐行高亮与点句跳播
- 收藏、歌手页、专辑页、歌单详情（播放全部）
- 下载（含歌词/封面）、下载页管理、已下载文件**离线播放**
- 均衡器（10 段 + 预设，设置持久化，与桌面同一份配置）
- 酷我 / 网易云 网页登录、网盘（S3）配置与歌单浏览

## 还没做

- 网盘导入队列、完整性修复的完整交互（接口在，界面只做了一半）
- 收藏/歌单的批量管理、本地音乐扫描
- 部分桌面专属能力不会移植：托盘、自动更新、窗口主题

## 怎么装

### 方式 A：自签名（推荐给开发者）

    # 1. 依赖
    brew install xcodegen cocoapods
    rustup target add aarch64-apple-ios aarch64-apple-ios-sim
    pnpm install

    # 2. 生成工程并装 Lynx
    cd mobile/native/ios
    xcodegen generate && pod install

    # 3. 用 Xcode 打开 TinyMusic.xcworkspace，选自己的开发者账号签名，
    #    Bundle Identifier 改成自己的（默认 com.tinymusic.app），真机运行

Rust 静态库与 Lynx bundle 由 Run Script 自动构建，不需要手动拷文件。

### 方式 B：TestFlight

需要付费开发者账号。把 `mobile/native/ios` 的签名改成一个 App Store 连接里创建的 App ID，
Archive 后上传即可。注意：App 内含网页登录与第三方音源，**上架审核有风险**，本项目只做内测分发。

## 已知限制

1. **音源版权**：部分歌曲是 VIP 音质，可能只能拿到较低档位；播放失败会在界面上报错。
2. **网盘 S3 未做真机验证**：本仓库没有可用的测试桶，配置与浏览界面已就绪，导入/校验请自备桶再试。
3. **均衡器**：对流媒体与本地文件都生效，但只支持 iOS 16+ 的 AVPlayer 音频处理 tap；不支持的音频格式会静默跳过。
4. **下载目录**：固定为 App 的 Documents/TinyMusic，可在「文件」App 里看到；卸载 App 会一起删掉。
5. **数据**：配置与下载记录都是本机文件（settings.json + sqlite），没有云同步。

## 验收清单（每次发内测包前跑一遍）

    ./mobile/scripts/smoke.sh /tmp/a.png TM_AUTOPLAY=1 TM_OPEN_PLAYER=1   # 播放页
    ./mobile/scripts/smoke.sh /tmp/b.png TM_OPEN_EQ=1                     # 均衡器
    ./mobile/scripts/smoke.sh /tmp/c.png TM_TAB=downloads                 # 下载页
    ./mobile/scripts/smoke.sh /tmp/d.png TM_SEARCH_KIND=playlist          # 搜歌单
    pnpm -F @tinymusic/desktop build && cargo test -p tinymusic-app        # 双端不回归

截图落在 `/tmp`，日志里应当能看到 `[TinyMusic] 后端已启动` 与 `audio.play()`。
