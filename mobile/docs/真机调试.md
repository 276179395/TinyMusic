# 真机调试（把 TinyMusic 装到自己 iPhone 上）

模拟器里已经全部验证过；真机只多一件事：**签名**。工程本身已经能编译出 iphoneos 版本
（`aarch64-apple-ios` 的 Rust 静态库 + Lynx bundle 都会自动打进 App）。

## 0. 前置

- Mac 上装了 Xcode（本项目在 Xcode 27.2 验证）
- iPhone 用数据线连上 Mac，手机上点「信任此电脑」
- Xcode → Settings → Accounts 里登录你的 Apple ID（**免费账号就够**，不用付费开发者）

## 1. 手机打开开发者模式（iOS 16+）

设置 → 隐私与安全性 → 开发者模式 → 打开 → 重启手机。
（这个开关只有在手机连过 Xcode 之后才会出现。）

## 2. 写入你的 Team ID 和 Bundle ID

    ./mobile/scripts/device-setup.sh ABCDE12345
    # 或者顺手改掉 Bundle ID（真机上必须唯一）：
    ./mobile/scripts/device-setup.sh ABCDE12345 com.yourname.tinymusic

Team ID 从哪来：

- Xcode → Settings → Accounts → 选中账号 → 右边 Team 列表里的 10 位 ID
- 或 `security find-identity -v -p codesigning`，括号里那串就是

脚本会改 `mobile/native/ios/project.yml` 里的两行，然后自动 `xcodegen generate` + `pod install`。
想还原：`git checkout mobile/native/ios/project.yml`。

> 为什么要重跑 `pod install`：xcodegen 会重写 .xcodeproj，CocoaPods 的集成会被清掉，
> 不重装 Pods 就会出现 `Pods-TinyMusic-resources-*.xcfilelist` 找不到的报错。

## 3. 连设备跑起来

    open mobile/native/ios/TinyMusic.xcworkspace

- Xcode 顶部 scheme 选 **TinyMusic**，运行目标选你的 iPhone
- ⌘R

首次启动会被拦：手机 设置 → 通用 → VPN 与设备管理 → 信任你的开发者证书。
之后再点一次桌面图标即可。

## 4. 确认跑的是对的

App 里应该看到：底部 5 个 Tab（首页 / 下载 / 网盘 / 账号 / 设置），首页有推荐列表。
日志（Xcode 控制台或 `xcrun devicectl device console --device <ID>`）应出现：

    [TinyMusic] 后端已启动: http://127.0.0.1:<port>
    [TinyMusic] Lynx bundle 来自内置资源: .../main.lynx.bundle

后端是**在 App 进程内**起的（`crates/ffi`），只绑 127.0.0.1，不依赖电脑。

## 5. 用热更新（可选，改前端不用重装）

1. Mac 上：`pnpm dev:mobile`（rspeedy，端口 3000）
2. `./mobile/scripts/device-devserver.sh` —— 它会打印你 Mac 的局域网地址
3. 在 Xcode 里给 Scheme 加环境变量 `TM_DEV_SERVER=http://<Mac 局域网 IP>:3000/main.lynx.bundle`
   （Product → Scheme → Edit Scheme → Run → Arguments → Environment Variables）
4. ⌘R；日志里应出现「Lynx bundle 来自 dev server: ...」

手机和 Mac 要在同一个 Wi-Fi。首次连接会弹「允许 TinyMusic 访问本地网络」，选允许
（Info.plist 里已经写了用途说明）。

## 真机上值得手动过的检查

- [ ] 首页推荐能出内容（网络不好时给错误提示，不白屏）
- [ ] 搜一首歌 → 点播 → 进度走、能听到声音
- [ ] 锁屏/控制中心能看到歌名，暂停/下一首能操作
- [ ] 切后台继续播（Info.plist 有 `UIBackgroundModes: audio`）
- [ ] 拔耳机 / 来电：自动暂停，回来手动继续
- [ ] 下载一首 → 「文件」App → 我的 iPhone → TinyMusic 里能看到 mp3 和 lrc
- [ ] 均衡器开「流行」预设，声音有变化；杀进程重开仍是开启状态
- [ ] 网盘页（如果配了 S3）能列歌单

## 常见问题

| 现象 | 处理 |
|---|---|
| 报 `Signing for "TinyMusic" requires a development team` | 第 2 步没做，或 Bundle ID 与别的 App 冲突，换一个 |
| 安装后图标是灰的 / 打不开 | 手机 设置 → 通用 → VPN 与设备管理 → 信任证书 |
| 7 天后闪退 | 免费 Apple ID 签名有效期 7 天，重新 ⌘R 一次 |
| Xcode 里看不到手机 | 数据线换一根（要能传数据的）、重插、Trust 这台电脑 |
| 白屏 | 看日志：`后端已启动` 与 `Lynx bundle 来自...` 是否都有；没有 bundle 就是忘了 `pnpm build:mobile` |
| 热更新连不上 | 手机与 Mac 不同网段；或「本地网络」权限被拒（设置里重新打开） |
| 有的歌放不出来 | 音源是 VIP 档，后端会降档或报错，换一首试 |

## 已验证到什么程度

- `xcodebuild -sdk iphoneos -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build` → **BUILD SUCCEEDED**，
  日志里能看到 `Rust 静态库就绪: aarch64-apple-ios/debug` 与 `已打入 Lynx bundle`。
- 也就是说：真机上唯一没被自动验证的就是**签名与你设备上的运行时表现**（后台播放、锁屏、下载目录可见性等），
  这些需要你按上面的清单过一遍。
