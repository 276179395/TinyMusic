# 桌面 ↔ mobile 功能对照

更新时间：2026-11-16（round 13）

| 桌面功能 | mobile 状态 | 说明 |
|---|---|---|
| 搜索歌曲 | ✅ | 首页「搜索」段，酷我 |
| 搜索歌单 | ✅ | 搜索段「歌单」子页签，点进歌单详情 |
| 每日推荐 | ✅ | 网易云 recommend_songs（未登录也能出结果） |
| 推荐歌单 | ⚠️ | 已接线，接口常返回空 |
| 歌单详情 / 播放全部 | ✅ | PlaylistPage，队列直接进播放器 |
| 歌手页 | ✅ | 播放页「歌手」进入，曲目列表 + 播放全部 |
| 专辑页 | ✅ | 播放页「专辑」进入，同上 |
| 播放（流代理） | ✅ | AVPlayer + 本地 Range 代理，锁屏/线控/中断已接 |
| 播放队列 / 随机 / 循环 | ✅ | 与桌面共用 packages/shared/player/queue |
| 全屏播放页 | ✅ | 封面/进度/控制/音质条/收藏/歌手/专辑入口 |
| 歌词（高亮、点句跳播） | ✅ | LRC 来自 api.detail（放在播放页内，桌面是独立页） |
| 音质切换 | ✅ | 档位门控共用 shared/quality |
| 下载单曲 | ✅ | 端到端验证（mp3+lrc 落盘） |
| 下载页 / 失败重试 | ✅ | 列表 + 重试/忽略 |
| 本地文件播放 | ✅ | 下载页点行离线播放（桌面 downloads 页对等） |
| 设置（下载目录/音质/并发） | ✅ | iOS 目录固定为 Documents |
| 均衡器 | ✅ | 10 段 + 预设；MTAudioProcessingTap 挂在 AVPlayer 上（流/本地都生效）；持久化在共享 settings |
| 收藏 | ✅ | 播放页 ♡ 收藏/取消，账号页列表 + 播放全部（与桌面同一份数据） |
| 我的歌单 | ⚠️ | 列表已接（未登录时为空） |
| 网页登录（酷我/网易云） | ⚠️ | WKWebView 已接，真实回填待手验 |
| 网盘 S3 浏览 | ✅ | 本地 S3 桩验证：歌单列表、曲目、完整性检查均通 |
| 网盘导入 / 完整性修复 | ✅ | 桩上验证：上传 mp3/lrc/jpg → 删文件 → 校验 → 修复补回 → 复查 0 issue |
| 列表批量操作（多选下载/删除/收藏） | ❌ | 桌面有 BatchBar，移动端未做 |
| 托盘 / 自动更新 / 窗口主题 | — | 桌面专属，移动端不做 |

## 说明

- 「✅」= 模拟器实测过；「⚠️」= 代码与界面就绪但缺少真实环境验证；「❌」= 未开始；「—」= 设计上不做。
- 所有业务规则都在 `crates/app` 与 `packages/shared`，移动端只写界面与原生壳能力。
- 验收方式见 `mobile/README.md` 的「冒烟脚本」与 `mobile/docs/内测包.md`。
